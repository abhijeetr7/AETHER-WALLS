# AETHER-WALLS
AETHER // WALLS — Next-Gen Wallpaper Gallery.

I have created the AETHER // WALLS wallpaper gallery web application in a single, self-contained HTML file.

Key Highlights & Integration Readiness:
Dark-Mode Glassmorphic Aesthetic: Built on #09090b obsidian surfaces with ambient glow orbs, frosted backdrop-filter: blur panels, 1px translucent borders, and violet/cyan gradient accents paired with Inter and JetBrains Mono.

Multi-Dimensional Filtering: Instant real-time search across titles, tags, and authors, combined with horizontal category pills, dominant color tone swatches, aspect ratio toggles (16:9, 9:16, 21:9), and persistent localStorage Saved Wallpapers.

Interactive Device Mockup Lightbox: Clicking any wallpaper opens a full-screen preview modal where you can toggle between Clean View, Desktop Monitor (with taskbar), and Phone Lockscreen (with live system clock/date) alongside clickable hex color swatches and keyboard navigation (←, →, ESC).

API-Ready Architecture: All wallpaper items are driven by the structured WALLPAPERS_DATA array at the top of the <script> tag, making it straightforward to connect to your backend API or port into React/Angular components.
